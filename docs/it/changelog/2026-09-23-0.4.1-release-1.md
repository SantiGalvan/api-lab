# Spostare la collection Postman di MyTask dentro apps/mytask/ e smettere di tracciarla

## Contesto
La collection Postman (`MyTask.postman_collection.json`) era alla radice del repository — materiale di riferimento usato durante il grilling per ancorare il design di `apps/mytask/`, ma vive accanto allo strumento invece che accanto all'app che documenta. Contiene inoltre quella che sembra una vera email/password admin nel body di esempio della richiesta `Authenticate`, quindi non deve essere tracciata da git. Richiesta di housekeeping diretta dell'utente, non legata a uno dei quattro ticket di build-out.

## Tracking
Nessuno — richiesta ad-hoc, non un ticket tracciato (vedi `docs/agents/issue-tracker.md`).

## Motivazione
Circoscrivere la collection sotto `apps/mytask/` invece che alla radice del repo rispecchia il principio "una cartella per app" già usato per `config.js`/`api.js`/`scenarios/`: il materiale di riferimento di un'app vive con quell'app. Ignorarla invece di committarla evita di mettere sotto version control un file con una credenziale dall'aspetto reale, invece di affidarsi a un futuro redacting o rotazione.
