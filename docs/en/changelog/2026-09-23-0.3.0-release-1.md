# MyTask: login auth mode and per-run authMode switching

## Context
Ticket 3 of the api-lab build-out, blocked by Ticket 2's m2m CRUD. MyTask's real API also accepts a `login`/password flow (per ADR 0001), used to simulate the real app as a specific user instead of poking the API with a fixed m2m token. This ticket wires that second mode into `apps/mytask` end to end.

## Tracking
Ticket 03 — "Login e authMode switching" — tracked in memory (see `docs/agents/issue-tracker.md`), not as a GitHub issue.

## Technical changes
```js
// apps/mytask/api.js — MyTask hands the session token back as a response
// header, not a body field, so authenticate() reads it from there.
async function authenticate(baseUrl, credentials) {
  const result = await post(buildUrl(baseUrl, 'authenticate'), { auth: credentials });
  const token = result.headers.get('token');
  if (!token) {
    throw new HTTPError(result.status, result.body);
  }
  return token;
}
```

```js
// core/auth/auth.js — refresh() lets a domain function force an immediate
// login (e.g. api.login(email, password)) instead of waiting for the lazy
// first-request/401 path to kick in.
async refresh() {
  cachedValue = await login();
  return cachedValue;
},
```

## Rationale
`login()` reuses `createLoginAuthStrategy`'s existing lazy-login/refresh-on-401 machinery (from Ticket 1) rather than duplicating it: it just overwrites the shared `credentials` object and calls the strategy's new `refresh()` to force a login now, so the same cached token then serves both the explicit call and any subsequent automatic refresh. Exposing response `headers` on the shared client (rather than a one-off `fetch` call inside `apps/mytask`) keeps every domain function going through `core/client`, and makes the same capability available to any future app whose API returns tokens or metadata via headers. `login()` throws synchronously when called outside `login` mode instead of silently no-opping, since a m2m-mode agent calling it almost certainly has a wrong assumption about the run's auth mode.
