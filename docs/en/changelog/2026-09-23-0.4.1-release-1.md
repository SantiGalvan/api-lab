# Move the MyTask Postman collection into apps/mytask/ and stop tracking it

## Context
The Postman collection (`MyTask.postman_collection.json`) was sitting loose at the repo root — it was the reference material used during grilling to ground `apps/mytask/`'s design, but it lives next to the tool itself instead of next to the app it documents. It also contains what looks like a real admin login/password in its `Authenticate` sample body, so it shouldn't be tracked by git at all. Direct housekeeping request from the user, not tied to one of the four build-out tickets.

None — ad-hoc request, not a tracked ticket (see `docs/agents/issue-tracker.md`).

## Rationale
Scoping the collection under `apps/mytask/` instead of the repo root matches the "one folder per app" principle already used for `config.js`/`api.js`/`scenarios/`: reference material for an app lives with that app. Ignoring it rather than committing it avoids putting a file with a real-looking credential under version control, instead of relying on redacting or rotating it later.
